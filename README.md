# Java Exercises

A sandbox repository to track my progress as I learn Java and object-oriented programming concepts.

## 🚀 Concepts learnt

### Core Basics
* **Variables:** Storing and updating different data values.
* **User Input:** Reading data typed into the console by the user.
* **Console Output:** Printing text, data, and results back to the screen.

### Logic & Control Flow
* **Conditionals:** Using if-else statements to let the program make decisions.
* **Loops:** Repeating blocks of code automatically (for/while).
* **Switch Statements:** Choosing between multiple fixed options efficiently.

### Data Management
* **Data Types:** Working with numbers, decimals, and booleans.
* **Strings:** Handling, combining, and manipulating text.
* **Arrays:** Storing fixed lists of matching data items.

### Structure & Object-Oriented Programming (OOP)
* **Methods:** Creating reusable blocks of code to perform specific actions.
* **Classes & Objects:** Building code blueprints and creating real instances of them.
* **Constructors:** Initializing new objects with their starting data.
